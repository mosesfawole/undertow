Which alert holds the story together?

Every revealed alert is removed in turn. The rows rank classification changes first, then absolute change in ask-side balance. Select any scenario to apply it to the whole investigation.

Balance = (ask-call − ask-put) / total ask premium. Between −20% and +20% is two-sided. This is a sensitivity test at fixed thresholds, not a probability or evidence of future returns. Related alerts can overlap; group effects are not tested.
